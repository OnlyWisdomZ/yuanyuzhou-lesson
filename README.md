猿宇宙在线课堂项目，本质上来说更接近在线教育项目的定义。它无论在用户界面还是在管理员界面，我都选用的是Spring Boot+MyBatis Flex框架，确保了数据逻辑的高效实现。在管理员的前端部分，采用的是Vue3+ElementPlus组合，为管理员提供了直观的数据展示页面。在用户的前端部分，我采用的是微信小程序的方案来进行实现。这样即可以发挥微信小程序简洁、便于使用的优势，又适合推广，也可以给用户视觉上较好的体验。采用MyBatis Plus的原因是 它可以根据数据库的表和字段来自动生成dao、Mapper层、Service层和Controller层的代码，可以让开发变得更加简便。
